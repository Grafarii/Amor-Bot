# SocioQuest — Psicologia Social

Jogo educativo gamificado para estudar **Psicologia Social** (2º semestre de Psicologia), baseado no plano de ensino UNIP.

## Conteúdo

4 unidades com lições, quizzes, associações, chefes e modo revisão:

1. O Campo da Psicologia Social
2. Psicologia Social nos EUA
3. Psicologia Social Europeia
4. Psicologia Social no Brasil

## Jogar

Abra `index.html` no navegador ou use o link de deploy.

## Tecnologias

HTML, CSS e JavaScript vanilla. Progresso salvo em `localStorage`.
