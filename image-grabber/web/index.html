Site Image Grabber

Crawls a site or directory index and downloads every image it can find — including ones hidden in comments, CSS, scripts, sitemaps, lazy-load attributes, and off-screen markup.

Only use this on sites you own or have permission to copy. Hidden images include display:none, <!-- comments -->, data-src lazy loads, and URLs buried in CSS/JS.

Limits locked — same site, robots.txt, depth 4, 500 pages.

Admin crawl seeds /users/, /media/, /uploads/ and the rest of the public folders, then continues past the login page using your session. It does not break into admin panels or bypass other people’s access.
