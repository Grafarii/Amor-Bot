# Como deixar o NeuroQuest público

O jogo já está pronto na branch `gh-pages`. Falta **1 configuração no GitHub** (30 segundos):

## Passo 1 — Tornar o repositório público

1. Abra: https://github.com/Grafarii/Amor-Bot/settings
2. Role até o final → **Danger Zone**
3. Clique em **Change repository visibility**
4. Escolha **Make public**
5. Confirme digitando o nome do repositório

## Passo 2 — Ativar GitHub Pages

1. Abra: https://github.com/Grafarii/Amor-Bot/settings/pages
2. Em **Build and deployment** → **Source**: escolha **Deploy from a branch**
3. Branch: `gh-pages` | Pasta: `/ (root)`
4. Clique **Save**

## Passo 3 — Aguarde ~1 minuto

Seu link fixo será:

**https://grafarii.github.io/Amor-Bot/**

Abra no celular, sem login.
